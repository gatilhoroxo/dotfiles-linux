# dotfiles-linux

Legendery fiesta com Ubuntu e outros.
Configuração pessoal de ambiente Ubuntu.
E, principalmente, um gerenciador portátil de ambiente Linux.

## Resumo

Buscando facilitar o setup de ambiente linux em qualquer computador, tendo ou não nível de admin. 

## Garantias

Tem lógica modular, facilidade em adicionar ou retirar algo da lista de ferramentas, repositórios ou diretórios que são configurados. 

Nunca irá apagar algo sem confirmação do usuário. 

Um novo usuário precisaria apenas de 8 passos para configurar um computador recém-formatado.
