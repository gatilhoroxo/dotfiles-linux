# Padrões de Nomeação

categorias:

- is_* → responde uma pergunta (is_symlink, is_writable).
- *_exists → verifica existência (file_exists, directory_exists).
- ensure_* → garante um estado (ensure_file, ensure_directory).
- Verbos imperativos → executam uma ação (extract_file, download_file, clone_repository).
