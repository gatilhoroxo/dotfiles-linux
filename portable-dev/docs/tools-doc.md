# O que é o diretório tools

Representa ferramentas externas a esse projeto que são necessárias para seu funcionamento. 
Contém binários, scripts (para conseguir os binários ou repositórios) e repositórios dessas ferramentas para ser possível usar rapidamente sem muita dificuldade. 

## Subdiretórios

- `bin/`
- `scripts/`
- `submodules/`
